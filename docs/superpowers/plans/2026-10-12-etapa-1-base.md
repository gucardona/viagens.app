# Etapa 1: base do app de viagens — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Follow Ponytail (full): smallest complete change, stdlib first, no speculative options, `shortcut: <limit>, <when to upgrade>` comments on known limits.

**Goal:** Login, viagens, roteiro dia a dia, itens com endereço/pin/anexos, mapa e deploy na VPS, conforme o spec.

**Architecture:** Um binário Go (`package main` em `backend/`) serve `/api/*` e o front React compilado embutido via `go:embed`. SQLite em `DATA_DIR/viagens.db`, arquivos em `DATA_DIR/files/<id>`. Caddy na frente para HTTPS.

**Tech Stack:** Go 1.24 (`net/http` ServeMux com métodos e `{id}`, `database/sql`, `log/slog`), `modernc.org/sqlite`, `golang.org/x/crypto/bcrypt`; React 18 + TypeScript + Vite, `react-router-dom`, `@tanstack/react-query`, Tailwind v4 (`@tailwindcss/vite`), `maplibre-gl`, Vitest; Docker Compose + Caddy; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-12-etapa-1-base-design.md`

## Global Constraints

- Nenhuma API paga do Google. Busca de endereço: Nominatim (`https://nominatim.openstreetmap.org/search`), `User-Agent: viagens.app (self-hosted)`, no máximo 1 req/s, timeout 5 s.
- Estilo do mapa: `https://tiles.openfreemap.org/styles/liberty`.
- Dependências Go: só `modernc.org/sqlite` e `golang.org/x/crypto`. Nada de roteador, ORM ou lib de migração.
- Env: `DATA_DIR` (padrão `/data`), `ADDR` (padrão `:8080`), `COOKIE_SECURE` (padrão `true`; `false` só em dev).
- Cookie `session`: `HttpOnly`, `Secure` (conforme env), `SameSite=Lax`, `Path=/`, 30 dias. No banco só `sha256(token)` em hex. Token: 32 bytes de `crypto/rand`, base64url.
- Escritas (`POST`, `PUT`, `DELETE`) em `/api/*` exigem `X-Requested-With: viagens`, senão `403`. Vale também para `/api/login`.
- Login: 5 falhas por e-mail (minúsculo) em 15 min → `429` até a janela passar.
- Upload: máximo 25 MB por arquivo (`413` acima). No disco o nome é o id; nome original só no banco.
- Erros: `{"error": "<mensagem em português>"}` com o status certo. JSON de entrada limitado a 1 MB, campos desconhecidos rejeitados (`400`).
- `kind` ∈ `flight, lodging, car, transport, restaurant, activity, event, note`.
- Datas `YYYY-MM-DD`, horas `HH:MM`, sempre texto local; vazio = não informado.
- UI em português, mobile-first.
- Commits terminam com as linhas de atribuição da sessão.

## Review Focus

1. **Nome de arquivo hostil ou com acento** (`../../etc/passwd`, `Passagem São Paulo.pdf`): nada é escrito fora de `files/`, e o download devolve o nome original correto no `Content-Disposition` (via `mime.FormatMediaType`). Teste na Task 3.
2. **Item com data fora do período da viagem** (voo de ida um dia antes do início): aparece num bloco de dia próprio, nunca some. Teste em `buildDays` na Task 6.
3. **Sessão expirada ou apagada**: API responde `401`, e o front volta para a tela de login sem tela quebrada. Teste Go na Task 1; `api()` redireciona na Task 6.
4. **Nominatim fora do ar ou lento**: `/api/geocode` responde `502` em até ~5 s com mensagem, e o formulário continua salvando sem pin. Teste na Task 4.
5. **Apagar viagem com anexos**: linhas e arquivos somem; erro ao remover um arquivo é logado e não impede o resto. Teste na Task 3.
